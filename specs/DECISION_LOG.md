| D-020 | 2026-07-26 | Blocking is configured by `blocking: { nonce?, reloadOnWithdraw? }` with no `enabled` flag; the declarative markup is the opt-in. | A page with no `data-cmp-category` element costs one `querySelectorAll` and nothing else, so a flag would only add config surface. | D-021 | 2026-07-26 | A gate naming a category or service that does not exist in the configuration stays blocked permanently, silently — no throw, no console output. | Fail closed: the alternative (throwing) lets stale markup break an entire page, and warning noise trains operators to ignore it. | D-022 | 2026-07-26 | Document order is enforced by a serialized promise chain: a `src` script without `async` sets `.async = false` and is awaited before the next gate runs; a script carrying `async` is inserted without being awaited; inline scripts run synchronously on insertion. | Script-inserted scripts are async by default, so order would otherwise depend on network timing. Awaiting non-async gates reproduces what the parser would have done. Scripts marked `async` running out of order is their declared semantics, so preserving that is correctness, not a gap. `error` resolves the chain as well as `load`, so one failing tag cannot stall the remainder. | accepted |
| D-023 | 2026-07-26 | On revocation, embeds are re-blocked (src removed, placeholder restored) while already-executed scripts are left untouched. `reloadOnWithdraw` (default `false`) reloads when an executed script's gate is revoked. | The spec (BLK-5) is explicit that scripts cannot be un-executed but silent on embeds; embeds are trivially reversible, so reversing them is the honest reading of a withdrawal. The reload cannot loop: after it, the denied script never executes. Default `false` because an unexpected reload is a worse surprise than a stale tag. | accepted |
| D-024 | 2026-07-26 | A gated element's own nonce wins over `blocking.nonce`, and the element's `nonce` IDL property is read before its attribute. | Per-element nonces exist precisely to be per-element. CSP nonce hiding blanks the content attribute after parsing, so `getAttribute("nonce")` alone silently loses the value and the re-created script would be refused by CSP. | accepted |
| D-025 | 2026-07-26 | The flagship `pre-consent-network-silence` E2E serves a vendored byte-identical copy of real `gtag.js` (`tests/vendor/gtag.js`, provenance recorded) via Playwright request interception, and keeps `navigator.sendBeacon` in place while proving interception observes it. | Spec §11.2 requires real `gtag.js`; vendoring keeps genuine Google code executing while removing CI dependence on network egress to Google and on Google-side changes. Deleting `sendBeacon` was the original plan and was dropped once interception was proven to cover it: the deletion was unnecessary unrealism. | accepted |

| D-035 | 2026-07-27 | `@libreconsent/core` resolves to `packages/core/src/index.ts` through a tsconfig `paths` mapping and a matching Vitest alias, rather than through the package `types`/`main` entry. | CI runs Typecheck, Lint and Unit tests before Build, and `dist/` is gitignored, so package-entry resolution made `packages/ui` fail on a clean checkout while passing on any machine that had built once. | D-036 | 2026-07-27 | BLK-4 patterns are plain case-sensitive substrings matched against the `src` as written, configured as `blocking.blocklist: [{ pattern, category, service? }]`. Not regular expressions. | A substring cannot backtrack pathologically on a hostile URL, stays JSON-serializable so `sameConfig()` singleton comparison needs no special case (as D-020 requires), and is smaller than RegExp compilation plus the escaping rules operators would have to learn. Hostname and path prefixes are all the net needs to express. | accepted |
| D-037 | 2026-07-27 | The net intercepts by patching the `src` setter and `setAttribute` on `HTMLScriptElement.prototype`, marking a matching script `type="text/plain"` plus `data-cmp-category` so it becomes an ordinary BLK-1 gate. The MutationObserver only *registers* those gates; it does not block. | The first implementation followed the industry fallback — detach the node and veto `beforescriptexecute` from the observer — and the E2E proved it ineffective: the blocklisted script still fetched and executed in Chromium. Per the HTML standard, inserting a `<script src>` prepares it and starts its fetch, and removing it does not cancel the execution that follows, because the element's node document is unchanged. Interception must therefore precede insertion, and the prototype is the only single-point entry. Marking the element inert instead of cloning it reuses `recreate()`, the ordered chain, and withdrawal semantics unchanged. | accepted |
| D-038 | 2026-07-27 | The guardrail scan reads `packages/{core,ui,bridge}/src`, not `dist/`, and carries an exported `EXCEPTIONS` allow-list that is empty at Phase 5. | CI runs unit tests before Build and `dist/` is gitignored (the P-021 failure mode), so a dist-based scan would pass vacuously on a clean checkout. With zero runtime dependencies and no build-time code injection, a source guarantee propagates to the artifact. Making a waiver an explicit reviewed diff — rather than a silently loosened regex — is what keeps LOG-4's future opt-in `fetch` from eroding the zero-network rule. | accepted |
| D-039 | 2026-07-27 | The layout-shift gate asserts an empty entry list rather than a CLS score under a threshold, and ships a companion test that displaces real content to prove the observer works. | Both consent surfaces are `position: fixed`, so the correct value is exactly zero and any entry is a real regression; a threshold would let one through silently. Asserting entries also names the element that moved. The companion test exists because `toEqual([])` is the classic vacuous assertion — it would pass equally well if the entry type were misspelled or unsupported. | accepted |
| D-040 | 2026-07-27 | A gated dynamic script holds its URL in `data-cmp-src` and never has a real `src` assigned. `recreate()` restores it on a grant. | Marking the element `type="text/plain"` alone is reversible: `s.src = url; s.type = "text/javascript"` before insertion resurrected the tag, and the element was still a registered gate so consent then ran it twice (P-026). An element with no source cannot fetch regardless of what is done to its type afterwards, and holding a pending URL in `data-cmp-src` is already the established convention for iframe gates (BLK-3). | accepted |
| D-041 | 2026-07-27 | The BLK-4 observer registers nothing until the first scan has run. | The observer also sees parser-inserted nodes, so registering during parsing put a gate parsed after `init()` ahead of one parsed before it, inverting BLK-1's document-order guarantee on any page that enabled the net (P-024). Nothing is lost: `apply()` does not run before the scan, and `scan()` finds every gate then in the document in one document-order query. An opt-in best-effort feature must not be able to weaken a stated guarantee. | accepted |
