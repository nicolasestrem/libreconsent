| D-020 | 2026-07-26 | Blocking is configured by `blocking: { nonce?, reloadOnWithdraw? }` with no `enabled` flag; the declarative markup is the opt-in. | A page with no `data-cmp-category` element costs one `querySelectorAll` and nothing else, so a flag would only add config surface. | D-021 | 2026-07-26 | A gate naming a category or service that does not exist in the configuration stays blocked permanently, silently — no throw, no console output. | Fail closed: the alternative (throwing) lets stale markup break an entire page, and warning noise trains operators to ignore it. Scanning happens after config validation, so a genuine config error has already been reported with a typed path. Region-inapplicable services fail closed through the same rule. | accepted |
| D-022 | 2026-07-26 | Document order is enforced by a serialized promise chain: a `src` script without `async` sets `.async = false` and is awaited before the next gate runs; a script carrying `async` is inserted without being awaited; inline scripts run synchronously on insertion. | Script-inserted scripts are async by default, so order would otherwise depend on network timing. Awaiting non-async gates reproduces what the parser would have done. Scripts marked `async` running out of order is their declared semantics, so preserving that is correctness, not a gap. `error` resolves the chain as well as `load`, so one failing tag cannot stall the remainder. | accepted |
| D-023 | 2026-07-26 | On revocation, embeds are re-blocked (src removed, placeholder restored) while already-executed scripts are left untouched. `reloadOnWithdraw` (default `false`) reloads when an executed script's gate is revoked. | The spec (BLK-5) is explicit that scripts cannot be un-executed but silent on embeds; embeds are trivially reversible, so reversing them is the honest reading of a withdrawal. The reload cannot loop: after it, the denied script never executes. Default `false` because an unexpected reload is a worse surprise than a stale tag. | accepted |
| D-024 | 2026-07-26 | A gated element's own nonce wins over `blocking.nonce`, and the element's `nonce` IDL property is read before its attribute. | Per-element nonces exist precisely to be per-element. CSP nonce hiding blanks the content attribute after parsing, so `getAttribute("nonce")` alone silently loses the value and the re-created script would be refused by CSP. | accepted |
| D-025 | 2026-07-26 | The flagship `pre-consent-network-silence` E2E serves a vendored byte-identical copy of real `gtag.js` (`tests/vendor/gtag.js`, provenance recorded) via Playwright request interception, and removes `navigator.sendBeacon` in the page. | Spec §11.2 requires real `gtag.js`; vendoring keeps genuine Google code executing while removing CI dependence on network egress to Google and on Google-side changes. Analytics prefers `sendBeacon`, so removing it forces transport onto interceptable fetch/XHR — otherwise "zero requests" could be satisfied by traffic the test never observed. | accepted |
| D-026 | 2026-07-26 | The BLK-2 CSP fixture declares its policy with `<meta http-equiv="Content-Security-Policy">` and omits the head-snippet marker. | The examples server has no response-header mechanism, and a meta policy exercises the same nonce enforcement in the browser. The injected head artifact carries no nonce, so including it would make the fixture fail for a reason unrelated to blocking. | accepted |
